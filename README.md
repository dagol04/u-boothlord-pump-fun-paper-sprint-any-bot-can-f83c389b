Sprint Rider: a paper-trading bot for pump.fun's 6-hour replay. It rides coins whose real SOL reserves cross 50 (completion candidates, on the way to ~85 SOL at migration) with a +30% take-profit / -10% stop-loss, and fills its 20-coin guardrail quota with minimum-size (0.01 SOL) early-momentum trades. Everything is decided from the harness state alone — no clock, no randomness — so the two graded executions produce identical action logs. Paper trading only; no real funds.

## Run it

```sh
node main.ts
```
